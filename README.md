# SportShop

He thong quan ly ban do the thao: khach hang xem/tim kiem/dat mua san pham, quan tri vien quan ly san pham, danh muc va don hang.

## Cong nghe
- Backend: Node.js, Express, SQLite (better-sqlite3)
- Frontend: HTML/CSS/JavaScript thuan
- Xac thuc: JWT

## Cai dat nhanh
Xem huong dan chi tiet tai `taiLieu/huongDanCaiDat.md`.

```bash
npm install
cp .env.example .env
npm run dev
```

## Cau truc thu muc
- `backend/` — API, cau hinh, middleware, cac module nghiep vu
- `frontend/` — giao dien nguoi dung
- `database/` — script tao bang, rang buoc, chi muc, du lieu mau
- `kiemThu/` — kiem thu tu dong
- `taiLieu/` — tai lieu du an (SRS, dac ta API, bao cao Sprint...)
